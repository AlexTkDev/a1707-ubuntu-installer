# MacBook Pro 15" (A1707, 2016-2017) Ubuntu Installer

Инсталлятор уровня **production-ready** для автоматической и безопасной настройки всех аппаратных компонентов MacBook Pro A1707 (MacBookPro14,3 / MacBookPro13,3) на базе Ubuntu LTS.

---

## 🚀 Возможности и ключевые особенности

- **Безопасная установка и откат (Rollback)**: При сбое во время установки происходит транзакционный откат всех изменений с использованием оригинальных бэкапов.
- **Манифестирование ресурсов**: Инсталлятор и деинсталлятор работают по манифесту (`/var/lib/macbook-installer/manifest.txt`), гарантируя, что системные файлы дистрибутива не будут случайно удалены.
- **Оффлайн и SHA256 проверка**: Поддержка проверки контрольных сумм SHA256 для всех файлов firmware (Wi-Fi, Bluetooth, FaceTime HD).
- **Динамический DKMS & Версионирование**: Автоматическое считывание версий модулей из `dkms.conf`, пиннинг Git-коммитов и проверка загружаемости модулей через `modinfo` после установки.
- **Поддержка Secure Boot**: Автоматическая проверка статуса EFI Secure Boot через `mokutil` с предупреждениями и руководствами.
- **Touch Bar & SPI**: Автоматическая валидация ядра и настройка модулей Touch Bar (`applespi`, `apple_ib_tb`, `intel_lpss_pci`).
- **Аудио и Камера**: Сборка и установка DKMS-драйверов Cirrus Logic CS8409 (`snd_hda_macbookpro`) и FaceTime HD (`facetimehd`).
- **Управление питанием**: Отключение проблемного гибернейта в `systemd` для корректного выхода из сна.

---

## 🛠️ Требования к системе

1. **Модель**: MacBook Pro 15" Touch Bar (A1707 — MacBookPro14,3 или MacBookPro13,3).
2. **ОС**: Ubuntu LTS (22.04 / 24.04 / 26.04) или совместимый дистрибутив семейства Debian/Ubuntu.
3. **Права**: Доступ к учетной записи `root` или права `sudo`.
4. **Свободное место**: Минимум 1 ГБ свободного места в `/`.

## 📖 Инструкция по использованию

### 1. Подготовка и запуск проверки (Dry-Run)

Перед применением изменений рекомендуем запустить инсталлятор в тестовом режиме (`--dry-run`), чтобы убедиться в совместимости железа:

```bash
sudo ./install.sh --dry-run
```

### 2. Запуск полноценной установки

Для запуска стандартной автоматической установки выполните:

```bash
sudo ./install.sh
```

### 3. Флаги и параметры запуска

- `--verbose` (`-v`) — Подробный вывод всех команд (логи сборки DKMS, `apt-get`, `make`).
- `--quiet` (`-q`) — Тихий режим вывода в консоль (выводятся только критические ошибки).
- `--dry-run` — Симуляция процесса без внесения изменений в систему.

**Пример запуска с подробным выводом:**
```bash
sudo ./install.sh --verbose
```

## 📋 Отчеты и логирование

- **Полный журнал событий**: `/var/log/macbook-installer.log`
- **Итоговый отчет об установке**: `/var/lib/macbook-installer/report.txt`
- **Манифест установленных файлов**: `/var/lib/macbook-installer/manifest.txt`

---

## 🗑️ Удаление и возврат к исходному состоянию

Если необходимо полностью и безопасно удалить все установленные драйверы, конфиги и прошивки с восстановлением бэкапов:

```bash
sudo ./uninstall.sh
```

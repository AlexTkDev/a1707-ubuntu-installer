# Security Policy

## Supported Versions

Only the latest stable release (v1.x) receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project (e.g., insecure backup creation, unsafe temporary file handling, privilege escalation vectors), please do NOT report it in the public issue tracker.

Instead, please send an email to `security@example.com` (replace with actual maintainer contact).

We will respond within 48 hours to acknowledge the report and work with you to release a patch.
